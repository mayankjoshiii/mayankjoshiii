## About

Business and data analyst with **nearly four years onsite at Google LLC** (Associate Analyst, via Vaco Binary Semantics) and an **MSc in Business Analytics (Distinction)** from Swansea University. I like starting from a business question and working back through the data to something people can act on.

Every project below has a **live interactive demo**, no installation needed. To be upfront about the data: the churn model uses a real public dataset and the job-market analysis uses a 25-listing sample, while the other dashboards run on **simulated data** generated in the browser to show the techniques. Each one says which it is.
